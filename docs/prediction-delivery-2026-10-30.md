## Qué funciona localmente

La pestaña **Predicción** del laboratorio envía la secuencia exacta del borrador a la API, solo con sesión y consentimiento por solicitud. La API reenvía texto plano a ESM Atlas sin el token del usuario; acepta una petición simultánea por proceso, una por identidad/minuto y tres por proceso/minuto. No instala GPU ni modelos en Vercel. El servicio público puede estar ocupado o no responder: no existe garantía de disponibilidad para las tres personas.

La API y el Worker comprueban el PDB, secuencia exacta y hashes. Se muestran coordenadas Cα, proveedor, modelo y fecha; se descarga el archivo original. No se inventan pTM, PAE, confianza ni revisión. Tampoco se alimenta al asistente con las cifras Colab anteriores desde esta pestaña. Cancelar, cambiar secuencia/variante/conjunto o cerrar sesión abandona respuestas pendientes. Cambiar secuencia retira su predicción; cambiar solo las protecciones la conserva, sin atribuirlas al predictor.

Guardar/reabrir conserva el experimento original y sus borradores en laboratorio portable v2; las predicciones son registros independientes. Se pueden compartir los archivos exportados; no se implementaron enlaces públicos ni nuevos buckets de Storage. El envoltorio del laboratorio continúa v1 y el workspace pasa a v4, con guardia monótona para clientes antiguos. No añade tablas ni Storage. Las dos banderas están desactivadas por defecto: `VITE_STRUCTURE_PREDICTION` en frontend y `FOLDING_ENABLED` en backend; ambas requieren `enabled` explícito.

## Revisión independiente y correcciones

Los dos chats de revisión leyeron código, pruebas y contratos sin modificar archivos ni ejecutar baterías. Coordinación aceptó dos hallazgos P2 y demostró cada regresión antes del arreglo:

- **Worker:** el primer recorrido reconocía `ATOM` tras recortar espacios/tabuladores, pero el parser geométrico solo leía el prefijo canónico `ATOM  `. Una línea con tabulador, otra cadena y `nan`, añadida a un PDB y con hash recalculado, podía omitirse y descargarse como validada. La prueba nueva falla antes y pasa después de exigir el mismo prefijo en ambos recorridos. Archivo de regresión: `src/features/design-lab/prediction.test.ts`, 4/4 tras el arreglo.
- **RPC:** la biblioteca entrega el plazo restante del cliente en `ctx.timeout_ms`, pero el método no lo aplicaba a Auth/predicción. Dos pruebas Connect (plazo 0/1 ms durante Auth y 10 ms durante proveedor) fallan antes y pasan después de envolver ambas fases, comprobar el plazo y responder `DEADLINE_EXCEEDED`. Conserva el límite de 30 s y libera el cupo en `finally`. Backend completo tras el arreglo: 146 descubiertas, 127 ejecutadas correctas + 19 SQL omitidas; la migración no cambió desde las 19 SQL correctas.

La frase sobre cancelación se precisó: cancelar una tarea Python libera su cupo; abortar la espera HTTP no acredita detección inmediata del cierre ni detención del cálculo externo. Ambos revisores confirmaron por lectura que los arreglos cierran sus hallazgos y no dejaron hallazgos materiales abiertos. Las pruebas las ejecutó coordinación. El pase final del frontend incluye las 715 unitarias, tipos, lint, build y PWA correctos.
